# 相棒の絵の指示文（画像生成AI用・第2版：ほぼ人の姿）

枠の中を**そのままコピーして貼り付けるだけ**で使えます（つなげたり入れ替えたりする必要はありません）。どの画像生成AIでも使えるよう英語にしています。

## 手順
1. 「1. 6人の並び」の A と B を両方試し、好きな頭身を選ぶ。気に入った1枚を `art/raw/lineup.png` として保存する。
2. 選んだ頭身（A か B）の「2. 1人ずつ」を6人分描く。1で気に入った絵を一緒に渡して「この絵柄で」と頼むと、絵柄がそろいやすい。
3. できた絵を `art/raw/` に、表の名前（`tsubu.png` など）で保存する。
4. 「絵を入れた」と伝える。私が3つの表情に切り分け、背景を消してゲームに組み込みます。かわいくない絵が出たときも、そのまま保存してもらえれば見て直します。

うまくいかないときは、貼り付けた文の最後に次の言葉を足してください:
- 大人っぽい → `younger, childlike, smaller body`
- 背景が白くない → `plain pure white background`
- 文字が入る → `no text, no letters`
