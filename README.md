# AddAll

小石を拾ってマナにほどき、町の人と過ごしながら、少しずつ完璧に近づいていく錬金術の放置ゲーム。スマホのブラウザで遊べます。

- 遊ぶ: https://arata-a3.github.io/AddAll/
- 画面の左上の版（v2.0 など）を押すと、変更の記録が見られます。

## スマホに入れる
**iPhone（Safari）**
1. Safari で上のページを開く
2. 下の共有ボタン（四角から上向きの矢印）を押す
3. 「ホーム画面に追加」→「追加」

**Android（Chrome）**
1. Chrome で上のページを開く
2. 右上のメニュー（縦に3つの点）を押す
3. 「アプリをインストール」または「ホーム画面に追加」を押す

一度開くと、インターネットにつながっていなくても遊べます。

## セーブ
- 5秒ごとに、そのブラウザの中へ自動で保存します。
- 機種を変えるときや、claude.ai の版から移るときは、設定（右上の歯車）の「書き出してコピー」で文字列を取り、新しい方の「読み込む」に貼り付けます。

## ファイル
| ファイル | 中身 |
|---|---|
| index.html | ゲーム本体（HTML・CSS・JS を1つにまとめたもの） |
| sw.js | サービスワーカー（オフラインで遊べるようにする） |
| manifest.webmanifest | ホーム画面に入れるときの名前とアイコン |
| icon.svg / icon-*.png / apple-touch-icon.png / og-image.png | アイコンとリンクのプレビュー画像 |
| 企画書.txt / 設計書.md / 現代版の案.md | 企画と仕組みのメモ |
